# 🚗 駐車管理システム (Parking Management System)

> 주차장 운영 업무의 효율적인 관리를 위한 개인 주차관리 시스템 프로젝트

<br>

## 📌 프로젝트 소개

**Parking Management System**은 주차장의 차량 및 정기권 정보를 관리하고, 차량의 입출고 현황과 주차 상태를 확인할 수 있도록 제작한 개인 프로젝트입니다.

실제 주차장에서 이루어지는 정기권 관리와 차량 입출고 업무를 바탕으로 기능을 구성하였으며, 데이터의 등록·조회 및 관리 과정을 시스템으로 구현하는 것을 목표로 하였습니다.

개인 프로젝트로 진행하여 기능 구성과 개발 과정을 직접 경험하였으며, 주차장 운영에 필요한 데이터 관리와 업무 프로세스를 이해하는 데 중점을 두었습니다.

<br>

## 🛠️ 개발 환경 및 기술 스택

| 구분 | 사용 기술 |
|---|---|
| Language | Java |
| Frontend | JSP, HTML, CSS, JavaScript |
| Backend | Servlet |
| Database | Oracle Database |
| Database Access | JDBC |
| Server | Apache Tomcat |

## 💡 프로젝트를 통해 배운 점

개인 프로젝트를 진행하면서 하나의 시스템을 구성하기 위한 기능 설계부터 데이터베이스 연동, 화면 구현까지 개발 과정을 직접 경험하였습니다.

Java와 JSP/Servlet을 활용한 웹 애플리케이션 개발 역량을 쌓았으며, Oracle 데이터베이스와 JDBC를 연동하여 데이터를 처리하는 방법을 익혔습니다.

또한 실제 주차장 운영 업무를 기능별로 구분하고 이를 시스템으로 구현하면서, 사용자의 입장에서 업무 흐름을 분석하고 필요한 기능을 설계하는 경험을 쌓았습니다.
